# AGENTS.md

This repo is a fan Arabic translation mod for Well Dweller (Switch, title `0100217023F6C000`, update **v1.0.3**) on the Eden emulator.
The Arabic text replaces the game's **Spanish** slot. Users run `Arabic-iTzFaisal.exe`, which installs the mod to `<emu>/load/0100217023F6C000/Arabic-iTzFaisal/romfs/`.

## Hard rules
- Never commit or ship game data. That covers `game.win`, `translations.ini`, NSP/NCA files, keys, and any file containing the original English or other-language text.
- Distribution is only: `patches/game.win.bsdiff`, `translation/arabic.json`, and the installer, which rebuilds the mod from the user's own copy. `.gitignore` enforces this. Before committing, check that `git diff --cached --name-only` has no `.win`, `.nsp`, `.nca` or `.keys` files.
- Use `uv run` for Python. Scripts declare their dependencies inline (PEP 723); there is no pyproject or venv. On Windows use `python -I`.

## Layout and flow
- `installer/install.py` is the single source of truth for discovery, version check, patch and install. It is also imported by `tools/build.py`.
  - `MOD_NAME`, `GAME_WIN_SHA256` and `PATCHED_WIN_SHA256` live here. If the patch or source changes, update the hashes; the install aborts on a mismatch.
- `installer/switchfs.py` is a custom NSP/PFS0 → NCA3 → BKTR update-patch → RomFS reader. Use it because nstool and old hactool fail on this game: nstool segfaults or fails the hash check on the BKTR update, and hactool 1.4 can't parse modern `prod.keys`. Notes:
  - AES-CTR counters use the **absolute NCA offset**.
  - The indirect table is decrypted through the AES-CTR-EX layer.
- `installer/translations.py`: `apply_arabic()` rewrites only the `[spanish]` values of `translations.ini` and keeps every other section byte-for-byte.
- Title keys come from NSP tickets, or from `<emu>/keys/title.keys[_autogenerated]`. Eden's autogenerated file stores the ticket's *encrypted* key. Candidates are verified by decrypting the ExeFS `PFS0` magic.

## Font pipeline (why game.win is patched)
- The game is GameMaker, compiled with YYC: there is no CODE chunk, so logic can't be edited. Text goes through **Scribble 9.3.1**, which already does Arabic joining (to Presentation Forms-B) and RTL. Only the fonts lacked glyphs.
- `tools/build_glyphs.py` reads the form tables from `tools/third_party/scribble_glyphdata.gml`. It renders each presentation form with HarfBuzz (ZWJ context) and FreeType into a new atlas per font: `fnt_default/2/3` use Noto Naskh Arabic, and `fnt_title` uses Lalezar on a 4096² page.
  - Don't switch to fonts that need contextual/cursive GPOS, such as Aref Ruqaa: joins break because Scribble only substitutes glyphs.
- Arabic cells share the Latin baseline and may be up to 20% taller (`GROW`). Scribble sets line height from the tallest glyph height.
- `tools/utmt/inject.csx` adds new texture pages to the `default` texture group (`IndexInGroup` = position in the group) plus new TPAG entries. The CSX scripts need the `WD_WORK` env var (`build.py` sets it).
- UTMT CLI 0.9.2 round-trips this `game.win` byte-identically, and the full build is deterministic. If the patch changes without intent, investigate.

## Commands
- Install from source (auto-discovery): `uv run installer/install.py [--romfs DIR | NSPs...] [--out DIR] [--no-pause]`. Use `--out` in tests so you don't overwrite the user's real Eden mod.
- Full rebuild: `uv run tools/build.py --utmt <UndertaleModCli.exe> [--work DIR]`. It writes `patches/game.win.bsdiff`, prints both SHA-256 values, and puts a test mod in `work/mod/`. It takes about 1.5 minutes; bsdiff accounts for most of that.
- Validate the translation: `python tools/validate.py <original translations.ini>`. It checks `[tags]` and `$`/`@`/`~` counts against English and rejects tashkeel, tatweel, Arabic-Indic digits and characters the fonts lack.
- Preview rendering: `uv run tools/preview.py work fnt_default out.png "نص"`.
- Release: `uv run tools/build_release.py` creates `dist/Arabic-iTzFaisal.exe` and `.zip` (PyInstaller one-file; the patch and `arabic.json` are bundled via `sys._MEIPASS`). Verify by unzipping to an empty folder and running the exe.

## Translation conventions
- Follow `translation/TRANSLATION_GUIDE.md` (glossary + hard rules).
- `$`/`@` are runtime placeholders. `~` is a line break. `[...]` tags are Scribble commands/events: keep them verbatim.
- `$` sometimes acts as a quote mark.
- Use Western digits and ASCII `"` quotes. The fonts only cover plain Arabic letters plus ، ؛ ؟.

## Testing in Eden
- The mod needs update v1.0.3 active. Eden loads it from game dirs when `ext_content_from_game_dirs=true`.
- The game's language is stored in its save (`blob.sav`: JSON with base64 `Settings.sav`, `"language":"spanish"` = Arabic, plus a trailing `\0`). Back it up before editing it, and restore it afterwards.
- Capture the Eden window with `PrintWindow` (DPI-aware). Don't focus the window or send keystrokes, because the user may be using the PC. A crash happened once after force-focusing or restoring the window.
